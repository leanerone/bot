# ETCH 刻蚀机台异常处置 SOP (示例文档)

> 适用范围: ETCH 群组 (ETCH-01 ~ ETCH-03) 等离子刻蚀机台
> 文件编号: SOP-ETCH-001 · 版本: V2.3 · 示例数据, 仅供演示

## 1. 射频功率漂移 (RF_PWR_DRIFT, 告警码 E0010)

**现象**: 射频功率读数偏离设定值 ±5% 以上, 刻蚀速率波动, 膜厚均匀性变差。

**处置步骤**:
1. 确认告警机台号与当前 lot, 立即暂停进片 (Hold)。
2. 检查 Match Network 电容位置是否漂移, 必要时执行 Auto Match。
3. 检查 RF 电源输出端子与线缆接头有无氧化、松动。
4. 用 Dummy Wafer 跑 Stability Test 3 片, 复测刻蚀速率。
5. 速率恢复至规格内 (目标值 ±3%) 方可解除 Hold, 否则开报修单通知设备工程师。

**升级条件**: 连续 2 次 Stability Test 不通过 → 升级至设备厂商 FSE。

## 2. 腔压越限 (CHAMBER_PRESS, 告警码 C2201)

**现象**: 工艺腔压力超出工艺窗口, 常伴随真空泵组异常音。

**处置步骤**:
1. 确认腔压当前值与设定值差值, 差值 >20% 时立即停止工艺。
2. 检查 Throttle Valve 开度反馈是否正常。
3. 检查干泵出口压力与 N2 吹扫流量。
4. 泄压后重新抽真空, 做 Leak Check (升压率 <5 mTorr/min)。
5. Leak Check 通过后执行 Seasoning (洁净腔体), 再恢复生产。

## 3. 日常点检要点

- 每班检查: 腔压基压、RF 反射功率、MFC 流量偏差。
- 每周检查: 干泵油位、Chiller 水温 (18~22℃)、Filter 压差。
- 记录异常时必须写明: 机台号、时间、告警码、当时生产的 lot 与产品。

## 4. 安全注意事项

- 进入维修模式前必须执行 LOTO (上锁挂牌)。
- 处理腔体部件必须佩戴防静电手套与护目镜。
- SF6/O2 等工艺尾气排放管路断开前先确认泵组停机。

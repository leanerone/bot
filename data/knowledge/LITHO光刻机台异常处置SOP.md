# LITHO 光刻机台异常处置 SOP (示例文档)

> 适用范围: LITHO 群组 (LITHO-01 ~ LITHO-03) 光刻/显影设备
> 文件编号: SOP-LITHO-001 · 版本: V1.8 · 示例数据, 仅供演示

## 1. 曝光能量漂移 (DOSE_DEV, 告警码 D0101)

**现象**: Daily Energy Check 超出 ±2% 规格窗口, CD 尺寸波动。

**处置步骤**:
1. 确认告警机台号, Hold 当前 lot, 禁止继续曝光。
2. 查看最近 3 次 Energy Check 记录, 判断漂移是阶跃还是缓变。
3. 阶跃: 检查光源灯箱/激光器状态, 通知设备工程师换灯或检修。
4. 缓变: 执行能量再校准 (Recalibration), 校准后连测 3 片确认。
5. 恢复生产前必须用 Monitor Wafer 验证 CD, 合格后解除 Hold。

**升级条件**: 换灯后仍漂移 → 升级厂商 FSE, 同步通知工艺工程师评估在制品。

## 2. 显影异常 (DEV_ABNORMAL)

**现象**: 显影后图案残胶/过显影, 与相邻 lot 对比异常明显。

**处置步骤**:
1. 检查显影液温度 (目标 23℃ ±0.5) 与喷嘴流量。
2. 检查显影液桶余量与更换日期, 超期先换液。
3. Track 热板温度记录导出, 确认 PEB ±0.5℃ 内。
4. 清洗喷嘴后用 Dummy 片验证, 再做 Monitor Wafer 确认。

## 3. 日常点检要点

- 每班检查: 光源状态灯、Energy Check 记录、显影液温度。
- 每周检查: 灯箱使用时长、Track 各温区记录、Filter 压差。
- 换胶批次必须记录胶批号, 回温不足 2 小时禁止上机。

## 4. 安全注意事项

- 深紫外光源运行时严禁直视光路, 检修必须佩戴 UV 防护镜。
- 显影液 (TMAH) 接触皮肤立即用大量清水冲洗并就医。
- 维修进入机台内部必须执行 LOTO (上锁挂牌)。

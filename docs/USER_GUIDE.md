# Fab Bot 用户手册 (v4.0)

> 面向: 工艺/设备/制造工程师。入口: `http://<服务器地址>:8100` (或企业微信内嵌)

## 1. 登录

- 浏览器打开入口地址, 输入 IT 分配的账号密码。
- 角色权限: **viewer** 只能问答; **user** 可问答 + 触发知识库导入; **admin** 另有管理后台。

## 2. 两个核心用法

### 知识问答 (SOP / 手册 / 经验库)
直接用自然语言提问, 回答下方会列出**引用来源** ([1][2] 编号 + 相似度)。
- 示例: 「射频功率漂移怎么处理?」「交班时最容易漏掉什么?」「Q-time 超时怎么办?」
- **重要**: 回答仅供参考, 执行处置动作前务必点开来源核对原文; 若回答未附来源,
  说明知识库未覆盖, 请勿采信。

### 数据查询 (WIP / 良率 / 机台 / 告警)
包含「多少 / 查询 / 良率 / 机台 / 告警 / 最近」等字样的问题会走数据查询,
返回 SQL 与结果表格 (只读, 上限 200 行)。
- 示例: 「最近未处理的告警」「ETCH 区几台机台 DOWN?」「P1234 最近一周平均良率」

## 3. 会话管理

- 左侧「+ 新会话」开始新话题; 会话自动保存在服务器, 换电脑登录也能看到。
- 对话中可以追问, 例如先问「最近有哪些告警」, 再问「那 ETCH-02 呢」。
- 对回答点 👍/👎 帮助团队改进质量 (管理员可在后台统计)。

## 4. 常见问题

| 问题 | 说明 |
|---|---|
| 回答说"知识库中未找到" | 知识库还没覆盖该主题, 请联系管理员补充文档 |
| 查不到数据 | 数据来自只读中间库 (定时同步), 非实时; 确认查询字段在权限范围内 |
| 忘记密码 | 找管理员在后台重置 |
| 回答有误 | 点 👎 并告知管理员, 会纳入评测集改进 |

## 5. 行为红线 (务必遵守)

- 不要在对话中输入与工作无关的个人信息;
- 本工具**不会执行**任何写操作 (Hold 批次/开单等), 一切动作以 MES 原系统为准;
- 问答记录全部留痕审计, 请按密级要求使用。

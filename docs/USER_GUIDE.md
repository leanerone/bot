# Fab Bot 用户手册 (v4.4.1)

> 面向: 工艺/设备/制造工程师。入口: `http://<服务器地址>:8100` (浏览器) 或桌面版 FabBot.exe。

## 1. 登录

- 浏览器打开入口地址, 输入 IT 分配的账号密码。
- 角色权限: **viewer** 只能问答 (技能执行置灰); **user** 可问答 + 知识库导入 + 技能执行;
  **admin** 另有管理后台。
- 令牌与浏览器绑定 (UA 摘要): 换浏览器/设备需要重新登录; 也可在设置里「全端登出」。
- 连续输错密码会临时锁定 (默认 5 次/10 分钟锁 15 分钟), 稍后再试或找管理员。

## 2. 两个核心用法

### 知识问答 (SOP / 手册 / 经验库)
直接用自然语言提问, 回答下方会列出**引用来源** ([1][2] 编号 + 相似度), 正文编号可点击溯源。
- 示例: 「射频功率漂移怎么处理?」「交班时最容易漏掉什么?」「Q-time 超时怎么办?」
- **重要**: 回答仅供参考, 执行处置动作前务必点开来源核对原文; 若回答未附来源,
  说明知识库未覆盖, 请勿采信。
- Notes 来源可点「在 Notes 中打开原文」(notes:// 回链, 需本机 Notes 客户端)。

### 数据查询 (WIP / 良率 / 机台 / 告警)
包含「多少 / 查询 / 良率 / 机台 / 告警 / 最近」等字样的问题会走数据查询,
返回 SQL 与结果表格 (只读, 上限 200 行), 可一键复制 SQL / 智能切图。
- 示例: 「最近未处理的告警」「ETCH 区几台机台 DOWN?」「P1234 最近一周平均良率」

## 3. Agent 模式 (多步工具)

- 对话输入框旁有 **🤖 Agent 开关**: 打开后助手会自动规划多步调用
  (知识检索 / 数据查询 / 告警值守 / 交班报告), 适合复合型问题,
  如「ETCH-02 最近告警多吗? 相关 SOP 怎么处理?」。
- 回答上方出现**步骤条**, 实时展示每一步工具与中间结果 (默认最多 3 轮, 管理员可配)。
- Agent 回答同样附来源、可 👍/👎; 普通单轮问题建议不开 Agent (更快)。

## 4. 技能中心

- 左侧菜单「技能」: 官方技能卡片 (rag 检索 / text2sql 查询 / alarm-watch 告警值守),
  展示权限徽章与工具标签; 点开详情看 SKILL.md 说明 (Markdown 渲染)。
- 在卡片参数框输入问题 → 「执行」; 结果弹层展示, 下方「最近执行」可回看历史 (状态/耗时/参数)。
- **viewer 角色执行为置灰** (只读), 需要 user 及以上权限。
- 含写操作的技能会弹**写确认卡**, 确认后才执行 (当前官方技能全部只读)。
- 技能执行全量审计, 请勿输入与生产无关的内容。

## 5. 会话管理

- 左侧「+ 新会话」开始新话题; 会话自动保存在服务器, 换电脑登录也能看到。
- 对话中可以追问, 例如先问「最近有哪些告警」, 再问「那 ETCH-02 呢」
  (超过 10 轮的历史会自动摘要压缩)。
- 对回答点 👍/👎 帮助团队改进质量 (管理员可在后台统计)。
- 流式回答可中途「停止」; 失败的消息带 **↻ 重试** 按钮, 一键重发同一问题。

## 6. 任务中心与交班报告

- 「任务」页: 我的任务增删改查 (仅本人可见) + 告警概览。
- **交班报告**: 选择时间窗 (默认 12 小时) 一键生成摘要 (告警汇总/机台分布/待办):
  - **导出 Word**: 下载 .docx 文件, 可直接打印/附入交班记录;
  - **推送到 Teams**: 摘要卡片发到班组 Teams 频道 (需管理员配置 webhook)。

## 7. 通知 (Teams / 飞书等)

- 告警值守开启后, CRITICAL/ALARM 告警会推送到配置的群渠道
  (公司内网默认 **Teams**, 卡片按级别配色: 红=CRITICAL / 橙=ALARM / 黄=WARN);
  也支持企微/钉钉/飞书。
- 桌面版: 托盘气泡 + 应用内铃铛红点面板 (点开看告警明细)。
- 渠道由管理员在 config.yaml 配置, 用户无需操作。

## 8. 管理后台 (仅 admin)

桌面版 UI 左侧菜单「管理」(或旧版入口 `/admin`), 五个页签:

| 页签 | 能力 |
|---|---|
| 统计 | 用户/会话/消息/好评差评/审计条目概览 + 推送测试 (选渠道) |
| 用户 | 创建用户 / 改角色 / 禁用启用 / 重置密码 (不能禁用或降级自己) |
| 审计 | 全操作留痕查询 (用户/接口/状态/耗时), 筛选 + **CSV 导出** |
| 会话 | 全用户会话查看与删除 |
| 配置 | 白名单键在线读写 (Mock 开关/模型名/top_k/限流/值守/Notes 模式), 保存自动备份; 敏感键 (密码/webhook/密钥) 永不回显 |

知识库管理在「知识库」页: 导入常规文档 / 上传 (.md/.txt/.docx/.pdf, 单文件 ≤10MB,
同名自动替换旧版本) / Notes 导入 / 全量重建 / 按来源摘除。

## 9. 桌面版 (FabBot.exe)

- 双击启动, 后端 sidecar 自动拉起 (首次运行自动落位配置与知识样例); 无边框窗口 + 托盘常驻。
- **全局热键 Ctrl+Alt+F**: 任意界面呼出/隐藏窗口; 关闭按钮默认收进托盘, 右键托盘退出。
- 数据目录 `backend\FabBotBackend\FabBotData` (配置/会话/知识库), 卸载不删除; 备份拷走该目录即可。
- 设置页可看服务状态 (模型/Mock/知识库片段数)。

## 10. 降级模式提示 (标黄) 是什么意思

- 配置了云端/远程模型但服务不可达时, 系统自动降级到 Mock 演示回答:
  回答首行会标注降级, 设置页状态标黄, `/api/health` 的 `llm.degraded=true`。
- **降级期间的回答不是真实模型产出, 请勿用于生产处置**; 模型服务恢复后自动复位, 无需重启。
- 管理员处理: 检查推理服务 (vLLM/Azure 端点) 是否在线, 见 DEPLOY.md 故障排查。

## 11. 常见问题

| 问题 | 说明 |
|---|---|
| 回答说"知识库中未找到" | 知识库还没覆盖该主题, 请联系管理员补充文档 |
| 查不到数据 | 数据来自只读中间库 (定时同步), 非实时; 确认查询字段在权限范围内 |
| 忘记密码 | 找管理员在后台重置 |
| 回答有误 | 点 👎 并告知管理员, 会纳入评测集改进 |
| 提示账号锁定 (423) | 失败次数过多, 等锁定期结束 (默认 15 分钟) |
| 上传失败 413 / 提问 422 | 文件超 10MB / 问题超 4000 字, 拆分后再试 |
| 换电脑后要求重登 | 令牌绑定浏览器 UA, 属正常安全行为 |

## 12. 行为红线 (务必遵守)

- 不要在对话中输入与工作无关的个人信息;
- 本工具**不会执行**任何写操作 (Hold 批次/开单等), 一切动作以 MES 原系统为准;
- 问答与技能执行记录全部留痕审计, 请按密级要求使用。
